Sichere Architektur

Pipeline der Datenverarbeitung

Der Weg von der rohen Zeichenkette zur verschlüsselten Serverless Function

1
📋

Frontend Input

Der Benutzer fügt den Text ein oder lädt eine Datei. JavaScript liest den Wert im DOM aus und verpackt ihn.

2
🔒

Netlify Function

Die Daten werden per POST an das Backend geschickt. Der API-Key ist sicher auf dem Server verborgen und für Nutzer unsichtbar.

3
🤖

Inferenz

Das Sprachmodell verarbeitet den Text über OpenRouter und generiert passgenaue Antworten.

4
✨

DOM Injection

Das Ergebnis wandert zurück ans Frontend und wird über JavaScript strukturiert ausgegeben.
